🔬 Database Normalization Breakdown (UNF $\rightarrow$ 3NF/BCNF)

1. 1NF Transformation

Eliminated comma-separated tracking checkpoint lists. Made all attributes atomic and assigned composite primary key $(\text{tracking\_no}, \text{timestamp})$.

2. 2NF Transformation

Removed partial dependencies. Separated parcel consignment details from physical transit movement audit entries into tracking_history.

3. 3NF / BCNF Transformation

Removed transitive dependencies where agent names and customer emails depended on foreign keys. Segregated into customers and delivery_personnel tables.
